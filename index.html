The build

Four phases.
One crew.

A new home closes in stages. Austin Air is there for the HVAC work each stage actually needs.

  1. 01

    Slab

    The ground is about to close. Before it does, the mechanical path has to be real: where the system will sit, how lines leave the house, and what the slab has to leave open.

  2. 02

    Frame

    Walls are open. This is the rough-in. Supply, return, the lineset path, and the control wire go in while a builder can still see the work.

  3. 03

    Set

    The house is dried in. Equipment is set, and the trim ties the rough-in to a system that can actually run.

  4. 04

    Start

    The system starts. Air moves. The builder is not left guessing whether the house will condition.
